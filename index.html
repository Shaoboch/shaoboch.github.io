Job Collection Report Uploader

A personal tool operated by Shaobo Cheng to upload job-collection reports and dated disaster-recovery backups from an Ubuntu server to the owner’s Google Drive.

The tool uses rclone and the Google Drive API. The owner signs in with Google and grants access before any upload. It uploads selected files, lists backup folders and checks uploaded contents to verify backups.

This tool is for the owner’s personal use. It is not a public service. This website provides information about the uploader; it does not accept Google sign-ins or store backup files.

Backup contents can include reports, job workbooks, runtime state and selected recovery configuration. Authentication credentials and browser login profiles are excluded from plain-text backup bundles.
