Privacy Policy

Effective date: 7 October 2026

This policy describes the personal Job Collection Report Uploader operated by Shaobo Cheng.

Access and purpose

The uploader requests Google Drive access with the owner’s explicit authorization. It uses that access to create dated backup folders, upload selected local files, list backup metadata and read uploaded files for integrity verification. Depending on the granted scope, its authorization may permit access beyond the backup folders; the backup workflow is restricted to its designated backup locations.

Storage and security

Backup data is stored on the owner’s Ubuntu server and in the owner’s Google Drive account. Backup folders are intended to remain private. OAuth credentials are stored separately on the server with restricted access and excluded from plain-text backups. Browser login profiles and other authentication files are also excluded.

Sharing and use

The operator does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. Data is transferred to Google to provide Drive storage. The backup workflow does not intentionally share backup contents with other people. The operator’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Dated backups remain until the owner deletes them. Removing authorization stops future authorized access but does not automatically delete existing backups. The owner can revoke the uploader’s access through Google Account permissions and delete backup files in Drive and on the server.

This website

This static information website is hosted by GitHub Pages. It has no sign-in form, application cookies or analytics added by the operator. GitHub may process visitor information to operate its hosting service under its own privacy policy.
